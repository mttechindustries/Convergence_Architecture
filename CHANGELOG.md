# Changelog

All material changes to the public Convergence Architecture repository are recorded here.

## 0.4.0 — 2026-08-04

### Data-driven public evidence system

- Replaced the hard-coded portal prototype with a registry-driven research application.
- Added 30 public-safe source records: 29 public records and one restricted placeholder.
- Added 30 atomic claim records: 28 public records and two restricted placeholders.
- Added 20 qualified pathway records: 18 public records and two restricted placeholders.
- Added 15 public-safe research trunks and one active public correction record.
- Added unified search across sources, claims, pathways, and trunks.
- Added complete source, claim, and pathway registries with filtering, sorting, pagination, deep links, and CSV/JSON export.
- Added linked detail views that traverse source-to-claim and source-to-pathway relationships.
- Added an interactive architecture graph generated from the pathway registry.
- Added evidence-distribution, source-timeline, and trunk-coverage charts calculated from registry data.
- Added runtime referential-integrity reporting and a dependency-free Python validator.
- Added GitHub Actions validation for data integrity, JavaScript syntax, and required static files.
- Added active correction and release-history views.
- Added local CSS, JavaScript, favicon, manifest, `.nojekyll`, and fallback routing with no Tailwind, Lucide, Google Fonts, or application-framework dependency.
- Preserved restricted canonical record counts through sanitized placeholders without exposing private testimony, controlled evidence, access paths, protected methods, or commercial material.
